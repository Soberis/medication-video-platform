## 1. 目的与判定规则

本清单配套 [V1.35 Consolidated Baseline](../requirements/baselines/V1.35/配药视频数据处理平台需求文档_V1.35.md)，用于把当前规范、支持性设计、运行手册和历史材料分层。分类是后续整理建议，不是删除授权。

- **ACTIVE**：当前需求、当前架构约束、当前审计证据或历史索引的入口；可被当前工作引用，但不能覆盖 V1.35 的产品语义。
- **MOVE_TO_HISTORY**：仍有迁移、兼容、审计或实现证据价值，但不应继续出现在当前规范入口；后续可在保持链接和 Git 历史可追溯的前提下移动。
- **DELETE_CANDIDATE**：纯临时计划或已无独立用途的文档；后续删除前仍需检查链接、外部引用和审计留存要求。
- **KEEP_AS_RUNBOOK**：运行、恢复、上传清理或环境验收手册；运行手册不等于产品需求，历史 UAT 手册另行归档。
- **NEEDS_DECISION**：代码、公开契约或当前工作仍可能使用，不能仅依据文件名归档或删除。

本次在保留内容和 Git 可追溯性的前提下修订需求与文档入口、补齐分类和事实更正，并完成四批历史文档归档。分类以正文用途与当前证据为准，不单凭版本号判断。

## 4. V1.35 的产品概念减法

V1.35 不是删除可靠性基础设施，而是删除或折叠重复的产品解释：

- 不再把 V1.29→V1.30→V1.31→V1.32→V1.33→V1.34 的继承链作为当前需求导航；改为一份自包含基线。
- 不再把 Cleaning 作为用户必须经过的产品阶段；Cleaning 新事实是否停止由 D1 决定。
- 不再把 Review 通过、Cleaning 通过和 Export Eligibility 解释成三套独立放行真源。
- 不再为项目导出范围设计第二套概念；当前项目列表的单选、多选和全选共用一个范围。
- 不再把独立 annotation task 页面作为第二个用户工作台；legacy redirect 暂时保留，任务视图收在视频工作区。
- project-scoped 标签 POST 不再作为目标产品入口，待 D4 和外部消费者确认后退役。
- 不引入 Hospital、Patient、Nurse、HIS 或 physical camera fleet 等平台产品实体。
- HDF5 主视频 candidates 重复 landmarks 只列为 D3 后续 layout 精简目标，本阶段不删除。

以下不属于减法对象：AI 与人工事实隔离、ClipAsset/model SHA、provenance、ai_job/attempt、inbox/outbox、lease/heartbeat、retry 和 idempotency。

## 5. 下一阶段安全候选与当前未解决事实

在对应决策明确并获得该项代码变更授权后，Platform 侧优先顺序建议为（不要求 D1–D5 同时完成）：

1. **Cleaning 收缩**：移除用户手工 recheck/重复流程或停止新的独立 Cleaning 事实；保留历史表、migration 和读取兼容。
2. **Export Eligibility 单一真源**：以现役后端校验链收敛最终判定；技术质量谓词由 D2 定义。V73 view 已由 V75 退役，不恢复旧 SQL，不删除各层独立职责的复验。
3. **project-scoped 标签 POST 退役**：先确认仓库外消费者，再同步 OpenAPI、客户端分支、测试和兼容说明。
4. **前端 status formatter 合并**：只收敛 presentation 层，不改变服务端状态。
5. **HDF5 layout 精简**：D3 确认消费者与兼容方案后评估；samples 只是全量 candidates 的区间子集，删除前需明确未标注区间样本的信息损失。

另有低风险候选 `CaptureGroupQualityQualifiedEvent.java` 及其 schema 登记：publisher 与自动派单已退休，空 listener 已删除；残留类、schema 与 quality-gate 需配套核查，schema 外部消费者未知。synthetic client 仍有“质量合格自动出现 task”的旧假设，后续先对齐显式 assignment；不得删除当前显式派单测试。该候选不是 Cleaning/D1 决策的替代，本轮不执行。

截至本清单日期，V1.34 动作链自身仍有只读审计记录的实现缺口（自动派发、任务 schema/provenance、执行元数据、confidence 可选性、候选当前 ClipAsset 过滤和人工采纳来源）。这些不在本阶段修复；Action Candidate 的技术设计保留为当前支持性 DRAFT。
