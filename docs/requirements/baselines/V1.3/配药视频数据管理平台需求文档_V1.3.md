# 配药视频数据管理平台需求基线 V1.3

> 文档版本：V1.3
> 文档状态：当前基线
> 生效日期：2026-07-21
> 前一版本：V1.2
> 生效规则：本版本继承 V1.2；本版本明确修改的条款优先于 V1.2 和其继承的 V1.1.13。

## 1. 本次变更

本平台由内部管理人员使用；医院侧 RK3588 或其他边端只负责采集并自动上传视频，不使用 Web 管理端，也不需要平台账号。

本次新增或澄清：

1. 管理端使用平台内部账号密码登录，不依赖医院 OIDC、医院 IdP 或医院账号；未来只有出现明确需求时才评估外部身份集成。
2. 账号只分管理员和普通用户。管理员管理平台账号、项目成员、项目、文件夹、视频删除和标注复核；普通用户仅在获授权项目内上传、查看、播放和完成分配任务。
3. 浏览器会话必须受服务端认证、HttpOnly Cookie 和 CSRF 保护；密码不得明文存储、传入 URL、写入浏览器持久化存储或提交到仓库。
4. 医院边端、媒体 Worker 和其他自动化调用使用独立服务凭据；不得复用任何平台管理账号或浏览器会话。

本版本不增加自注册、默认账号、默认密码、密码找回、第三方单点登录、多级角色或边端远程控制功能。

## 2. 身份、角色与项目权限

### 2.1 内部账号

- 首个管理员只能由环境运维配置在首次部署时引导创建；不提供公开注册。
- 管理员创建普通用户、启用/停用用户和分配项目成员的能力必须由服务端检查全局管理员角色，并记录审计证据。
- 平台账号全局角色不替代项目 Membership；用户能否看到、上传、播放或操作某个项目，始终由项目 Membership 和业务状态共同决定。
- 用户停用后不得创建新会话；现有会话的失效策略、密码重置和登录限流在对应安全切片中形成验收证据。

### 2.2 边端自动上传

- RK3588 只按正式 Upload/Multipart/Complete 协议上传采集的视频、元数据和事件日志。
- 边端不控制平台项目、文件夹、视频审核、标注或数据集；平台也不控制边端相机、机器人、PLC 或采集触发。
- 边端服务凭据最小权限、可轮换、与人员账号隔离，且不得出现在 Web、日志、仓库或浏览器中。

## 3. 需求编号调整

| 编号 | 类型 | 需求 | 最低验收 |
| --- | --- | --- | --- |
| FR-036 | 细化 | 管理员和普通用户 | 系统只提供 ADMIN/MEMBER 两种角色；所有接口同时检查内部账号、项目 Membership 和业务状态。 |
| FR-037 | 新增 | 平台内部账号登录 | 管理人员可使用平台账号登录、读取当前会话并安全退出；错误账号和密码使用同一安全提示；浏览器命令受 CSRF 保护。 |
| FR-038 | 新增 | 管理员账号管理 | 管理员可创建、启用/停用普通用户并分配项目成员；不存在公开注册和默认密码。 |

V1.2 的 FR-033～FR-035，以及 V1.1.13 的上传、播放、标注、清洗和数据集需求继续有效。

## 4. 验收场景

1. 未登录访问管理端业务路由时，被引导至登录页；不存在合法会话时 API 返回稳定的未认证结果。
2. 正确账号密码创建内部会话；错误账号与错误密码返回相同用户提示；退出后不能继续访问项目数据。
3. 浏览器通过 Cookie 会话执行项目、文件夹、删除和本地上传命令时，服务端校验 CSRF；缺失或错误 CSRF 被拒绝。
4. 管理员创建项目后获得其首个项目 ADMIN Membership；普通用户看不到未加入项目，也不能通过前端构造请求越权。
5. RK3588 自动上传在不使用 Web 登录的情况下继续通过独立服务凭据完成正式上传协议。
6. 管理员创建或停用普通用户、分配项目成员后，相关用户的可见项目和操作权限按服务端事实变化，并保留审计证据。

## 5. 实施边界

- 当前切片实现 FR-037 的登录、会话、退出、密码哈希和 CSRF 基础，以及 FR-038 的管理员创建/列出/启停普通用户和项目成员分配页面；账号角色提升、密码重置、登录限流和现有会话即时吊销不在本切片范围。
- 视频播放、隐私放行、标注、清洗和数据集仍按既有需求顺序推进；账号体系不改变这些业务状态机。
- HTTPS、会话失效、账号禁用即时失效、密码重置、登录限流和外部 IdP 是否引入，均在部署/UAT 前形成明确配置与证据，不能用默认值宣称已验收。
