# 配药视频数据管理平台需求基线 V1.2

> 文档版本：V1.2
> 文档状态：已批准
> 批准日期：2026-07-17
> 前一版本：V1.1.13
> 生效规则：V1.2 自批准之日起生效；未被本文件修改的 V1.1.13 条款继续有效，冲突时以 V1.2 为准。

## 1. 本次范围

本次增加或明确四项能力：

1. 医院侧远端上传拍摄的视频；用户也可以在平台页面上传本机视频。上传的视频可以播放，无用或不合格的视频可以删除。
2. 按项目和文件夹分类视频，不同视频可以放在不同文件夹中。
3. 第一版只有管理员和普通用户两种角色。
4. 支持视频数据标注。“标定数据”在本项目中按“视频数据标注”理解，不指相机内参、外参或手眼标定。

本次不增加远程地址抓取、多级目录、回收站或新的标注类型。

## 2. 视频上传、播放和删除

### 2.1 上传

- 医院远端上传：医院侧设备或系统通过平台接口上传拍摄的视频，沿用 V1.1.13 的分片上传、完整性校验和入库流程。
- 平台本地上传：用户在平台页面选择一个或多个本机视频，选择所属项目，文件夹可选；页面显示真实上传进度和失败原因。
- 两种入口使用同一套权限、文件校验和入库规则。上传成功后，视频出现在所属项目的视频列表中。
- 第一版中，本地选择的每个视频独立形成一个单视角 `CaptureSession`；平台不根据文件名或选择顺序推断多视角关系。
- 平台不主动从 HTTP、FTP、SFTP、SMB 或 NAS 地址抓取视频；以后确有需要时另立需求。

### 2.2 播放

视频完成入库并具备可播放版本后，授权用户可以在平台中播放。播放前检查项目权限、视频可用状态和隐私要求；不满足条件时给出明确原因。

### 2.3 删除

第一版只有管理员可以删除明确选中的无用、上传错误或质量不合格视频。

- 删除前显示目标视频并要求确认；
- 删除后，该视频不再出现在普通列表中，也不能继续播放或加入新的标注任务和数据集；
- 删除一个视频不得连带删除其他视频；如果它属于多视频拍摄任务，保留该任务和其他视频，并显示视频缺失或不可用；
- 记录删除人、删除时间和结果；
- 已被冻结数据集等受控结果引用的视频不得直接删除，应提示引用原因。

删除在平台中立即生效；底层对象和备份何时清理由既有保留与销毁规则处理，不在本次增加新的用户流程。

## 3. 项目和文件夹

- 每个视频属于一个项目，用户只能访问自己有权限的项目。
- 文件夹属于项目，只用于视频分类，不作为权限边界，也不对应对象存储目录。
- 第一版只支持一层文件夹；一个视频可以不放入文件夹，也可以放入一个文件夹。
- 视频只能在所属项目内移动文件夹，不能借此改变所属项目。
- 管理员可以创建、重命名和删除文件夹；删除文件夹只取消其中视频的分类，不删除视频。

## 4. 用户角色

| 角色 | 第一版权限 |
| --- | --- |
| 管理员 | 管理用户、项目和文件夹；上传、查看、播放和删除视频；创建标注任务并复核结果。 |
| 普通用户 | 在授权项目内上传、查看和播放视频；完成分配给自己的标注任务。 |

所有接口都必须在服务端检查角色和项目权限，不能只依赖前端隐藏按钮。同一用户不能复核自己提交的标注结果。以后需要复核员、质检员等新角色时，再通过新需求扩展。

## 5. 视频数据标注

视频数据标注沿用 V1.1.13 的 FR-011～FR-018，不重复建立另一套“标定”功能。第一版继续支持标注任务、Step 时间段、Object 对象、质量与隐私标签、提交、复核、退回和版本历史。

## 6. 需求编号

| 编号 | 类型 | 需求 | 最低验收 |
| --- | --- | --- | --- |
| FR-007～FR-008 | 既有需求细化 | 视频播放 | 已具备播放条件的视频可播放；无权限或未通过隐私要求时拒绝。 |
| FR-011～FR-018 | 术语统一 | 视频数据标注 | 使用既有标注与复核闭环，不创建重复功能。 |
| FR-033 | 新增 | 项目和一层文件夹 | 用户只能访问授权项目；视频可在所属项目内分类和移动。 |
| FR-034 | 新增 | 平台本地上传 | 用户可选择本机视频完成上传、校验和入库。 |
| FR-035 | 新增 | 视频删除 | 管理员可删除选中的无用或不合格视频；不连带删除其他视频，操作可审计。 |
| FR-036 | 新增 | 管理员和普通用户 | 系统只提供两种角色，接口同时校验角色和项目权限。 |

医院远端上传继续使用既有 FR-001～FR-005，不重复编号。

## 7. 验收场景

1. 医院侧设备或系统能够远端上传视频，平台完成校验和入库。
2. 用户能够在平台页面选择本机视频上传，并查看真实进度和失败原因。
3. 两种方式上传的视频都能在所属项目中查询和分类。
4. 授权用户能够播放具备播放条件的视频，未授权用户不能取得播放地址。
5. 管理员删除一个视频后，该视频不可继续使用，其他视频和所属拍摄任务不被连带删除。
6. 管理员能够创建文件夹并将视频分类；删除文件夹不会删除视频。
7. 普通用户只能访问授权项目，系统只提供管理员和普通用户两种角色。
8. 用户能够完成既有范围内的视频标注、提交和独立复核。

## 8. 实现与 UAT 参数

以下项目不改变已批准功能范围，但必须在对应实现或 UAT 前形成可配置值和验收证据：

1. 平台本地上传支持的媒体格式、单文件大小、批量数量和目标浏览器范围。
2. 平台本地上传在目标医院网络中的容量、中断恢复和失败重试边界。
3. 视频播放使用的编码规格、音轨策略、首帧和 seek 指标。
4. 视频底层对象、备份和保留期的清理规则。

这些参数不得通过不可追溯的代码常量伪装成业务结论。
