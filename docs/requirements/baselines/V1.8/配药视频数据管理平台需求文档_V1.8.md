# 配药视频数据管理平台需求基线 V1.8

> 文档版本：V1.8
> 文档状态：当前基线
> 生效日期：2026-07-27
> 前一版本：V1.7
> 生效规则：本版本继承 V1.7；本版本明确修改的条款优先于 V1.7 及其历史继承基线。

## 1. 本次变更

P0 Web 管理端只面向内部桌面工作站和笔记本电脑，不把手机浏览器、触摸优先操作或移动端独立布局纳入当前交付和 UAT 范围。

目标视口基线为：

| 场景 | 视口 |
| --- | --- |
| 笔记本最低验收 | 1366 × 768 |
| 常见笔记本 | 1440 × 900 |
| 1080p | 1920 × 1080 |
| 2K | 2560 × 1440 |
| 4K | 3840 × 2160 |

验收记录必须同时注明操作系统显示缩放比例。当前已有的窄屏回退样式可以保留，但不构成手机端兼容承诺，也不应扩大本阶段测试范围。

## 2. 桌面布局原则

1. 以 1080p 的信息密度为基础；2K 和 4K 通过分档扩大工作区，不通过整体缩放、放大字号或拉伸控件填满屏幕。
2. 内容区必须设置可解释的最大宽度，避免正文行长、表单和详情卡片无限拉伸；表格、项目列表和本地上传等工作台型页面可使用更宽空间。
3. 目标视口不得出现页面级横向滚动、主要操作遮挡、文字重叠或焦点不可见。列数确实超过可用空间时，只允许表格容器局部横向滚动。
4. 项目、Session、资产、标注和上传页面维持同一内容边界、标题层级、控件高度和操作对齐规则。
5. 宽屏增加的是有效工作区，不增加假统计、装饰面板、视频墙或不可执行操作。

## 3. 最低验收

1. 登录、项目、配药操作、视频资产、视频详情、标注任务、本地上传和管理页面至少在 1366 × 768、1920 × 1080、2560 × 1440、3840 × 2160 下完成真实浏览器抽查。
2. 项目列表行占满内容区，项目事实位于左侧，主入口和上下文管理操作稳定对齐在右侧。
3. 2K 和 4K 下列表、筛选和上传表单能利用额外宽度；播放器和长文本仍保持可读上限，不因宽屏无限放大。
4. 键盘操作、状态文字、错误反馈和短期播放授权等既有业务与安全规则不因布局分档发生变化。
5. 本阶段不以手机截图、手机浏览器或触摸手势作为验收证据。
