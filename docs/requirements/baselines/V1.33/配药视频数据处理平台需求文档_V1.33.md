# 配药视频数据处理平台需求基线 V1.33

日期：2026-09-08

状态：DRAFT / 待用户验收

继承 [V1.32](../V1.32/配药视频数据处理平台需求文档_V1.32.md)，仅调整导出选择范围。

- 导出只有当前项目一个范围。弹窗独立读取项目全部 CaptureGroup 摘要和授权范围为 PROJECT 的人工任务；主视频列表仍分页，不以主列表已加载记录作为导出数据源。
- P0 复用现有 cursor API，每页最多 100 条，读取至结束并按 ID 去重；中途失败、取消或游标循环不得把部分结果显示为完整候选列表。每次打开重新读取；不增加后台作业、缓存或新服务端接口。
- 正常列表只显示当前任务 COMPLETED 且当前 revision 为 APPROVED 的记录，文案为“可选择”。这是人工条件初筛，不代表最终导出准入。暂不提供不可选记录诊断列表。
- 默认不选；复选框实现单条、多条和全选，显示“已选择 N 条”。全选覆盖本次完整候选列表，下载始终传明确的所选 capture_group_id；不得通过省略 ID 把未展示的新记录纳入导出。零选择不能下载。
- 入口要求全局 ADMIN 与 ACTIVE 项目 ADMIN；候选任务响应必须为 PROJECT。服务端下载继续检查权限、合成数据配置、当前人工来源、provenance、MediaPipe 和 HDF5 准入，生成一个 HDF5；文件结构、samples、标签库和人工确认规则不变。
- 加载中不可选择；失败提供重试，取消关闭后终止读取并忽略迟到响应。下载失败保留选择，不自动跳过失效记录；重新打开可刷新候选。

验收：主视频仅加载第一页时，导出候选仍包含后续页；单选、多选及全选下载均准确携带所选 ID；未批准记录不出现；覆盖分页失败、取消、重新打开、权限范围和空列表；使用既有合成 fixtures 完成组件与浏览器回归。
