# 配药视频数据处理平台需求基线 V1.31

日期：2026-09-07  
状态：DRAFT / P0 实施中

## 1. 目标

在保留现有视频、MediaPipe 检测事实和人工标注审计边界的前提下，提供唯一的管理员 HDF5 数据导出。管理员可维护动作标签库，并在视频列表中选择一个、多个或当前列表内全部已完成标注的采集记录导出。

本版本继承 [V1.30](../V1.30/配药视频数据处理平台需求文档_V1.30.md) 的界面与业务边界；冲突时以本版本为准。

## 2. P0 范围

### 2.1 标签库

- 标签库由平台管理员管理，所有项目共享；普通成员只能读取当前标签。
- 管理员可新增一个 `PRIMARY_STEP` 动作标签：稳定英文 `label_id`、中文显示名称和说明均为必填。
- 新增标签发布一个新的不可变 label schema；新建标注任务使用新 schema，已有任务、revision 和已导出数据保持原 schema/digest，不编辑、不删除、不重写。
- P0 不支持编辑、删除、排序或按项目覆盖标签，避免破坏历史标签语义。

### 2.2 HDF5 导出

- 新增唯一的 `human-demonstration-hdf5.v1` 下载。`capture_group_id` 可重复指定一个或多个采集记录；缺省时导出全部合格采集记录。
- 仅导出当前输入和媒体 provenance 仍有效、人工标注已审核通过的记录；规则复用现有人工标注导出。没有合格记录时以明确错误拒绝，不生成空的“可训练”文件。
- 一个合格 `CaptureGroup` 为一个 HDF5 episode。文件包含：episode/source 视频身份与 SHA-256、已审核动作区间和标签 schema/revision provenance，以及每个当前可验证 MediaPipe Candidate 的源机位、源视频、时间戳、21 点和 AI provenance。
- HDF5 不包含 MP4 字节、对象存储键、预签名 URL、患者身份、机器人状态或控制动作。它是平台自定义的 `human-demonstration-hdf5.v1`，不是 LIBERO/robomimic 兼容文件；不得虚构 `states`、`actions`、reward 或 success。
- MediaPipe 是检测事实，人工标签是审核后的语义事实；二者位于同一 episode 的不同 HDF5 group，以视频 ID 和源时间关联，不互相覆盖。多机位不进行自动时间对齐，也不把主机位标签复制到参考机位。
- 当前仅允许 synthetic profile；非合成授权和导出仍等待人工治理审批。

### 2.3 界面

- 管理员在“设置”中可进入“标签库”，查看当前标签并新增标签；标签发布后新建标注任务使用新规范，历史任务继续绑定原规范。
- 视频列表只对已完成标注并通过复核的记录提供勾选；管理员可选择一条、若干条或从顶部“导出数据”下载项目内全部合格记录的一个 HDF5。详情页不提供导出入口。
- 下载前文案明确范围和 HDF5 所含内容；不新增数据集版本、异步导出队列或导出历史页面。

### 2.4 导出收敛

- 移除 `hand-landmarks.v1` CSV、`human-annotations.v1` CSV 及其预览、下载入口和 Web 菜单；平台不再提供 CSV 导出。
- HDF5 的 `annotations` group 保存人工审核语义事实，`views` group 保存关联的当前 MediaPipe 检测事实；它们共享视频身份与来源时间，但不互相覆盖。

## 3. 契约与验收

| ID | 需求 | 最小验收 |
| --- | --- | --- |
| V31-FR-001 | 新增标签发布不可变 schema | 管理员新增后新任务可用新标签；旧任务仍只接受旧标签；成员写入被拒绝 |
| V31-FR-002 | 单记录/多记录/全部 HDF5 导出 | 三种范围均下载一个 `.hdf5`；非管理员、无合格标注和 provenance 漂移被拒绝 |
| V31-FR-003 | HDF5 内容可回读 | 合成文件可由 HDF5 reader 读取 episode、标签、视频 SHA、landmark `[N,21,3]` 和 AI provenance |
| V31-FR-004 | 机器与人工事实不混淆 | 标签只写主机位的审核 revision；MediaPipe 保留每路源视频和时间戳；不输出虚构机器人 action |
| V31-UX-001 | 管理与导出入口 | 管理员可从标签库新增标签，并仅从列表勾选一个、多个或导出项目内全部合格记录；成员不见写入或导出入口 |

## 4. 非目标

- CSV、LIBERO / robomimic `states/actions` 兼容导出；
- LeRobot、RLDS、Parquet、视频打包、模型训练或机器人控制；
- 真实患者数据、生产导出、自动数据放行；
- 标签编辑、删除、项目专属标签库、数据集版本或导出作业系统。

V1.31 成为 CURRENT 前仍须完成合成数据契约、HDF5 回读、前端交互验证、用户验收和非合成治理评审。
