# Requirements Baselines

本目录保存已经编号和版本化的业务需求基线，不保存技术设计副本。

## 当前基线

- [配药视频数据管理平台需求基线 V1.17（手部检测优先）](./baselines/V1.17/配药视频数据管理平台需求文档_V1.17.md)

V1.17 自 2026-08-10 起为当前基线。平台名称和长期定位仍为“配药视频数据管理平台”。平台对接而不控制
医院边端采集系统，在云端完成“视频/数据管理 → MediaPipe 手部预标注 → Ego 配药动作标注与复核 → 数据
清洗 → 可用数据”的闭环。手部预标注是当前优先交付方向，但不能替代人工标注和清洗。视频库支持服务端
分页、时间/相机/来源/状态筛选；数据管理提供规模、来源、相机和质量状态概览。相机数量按每次采集动态决定，
不得写死为 3 路；测试视频的永久清理必须是独立、可审计、受确认的动作。

V1.17 继承既有安全、权限、审计、资产完整性与“机器结果不自动成为正式标注”的约束；发生冲突时以 V1.17 为准。

## 管理规则

- 已发布版本不原地覆盖；修订时建立新的版本目录。
- 增量基线可以显式继承上一版本，但必须写明继承关系、变更范围和冲突优先级。
- 未批准候选必须明确标记 RC/评审稿，不能称为当前基线。
- 当前版本通过本 README 和根 `README.md` 指向，不复制第二份“当前版”。
- 需求变更先更新需求基线，再更新架构追踪、技术设计、契约和测试。
- 文档不得包含真实患者视频、身份映射、医院账号、生产 URL、密钥或其他未授权敏感数据。
