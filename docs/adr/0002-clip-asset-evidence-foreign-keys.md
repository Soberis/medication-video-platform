# ADR-0002：ClipAsset 证据记录使用受限外键

- 状态：已接受
- 日期：2026-07-17

## 决策

`privacy_assessment` 和 `quarantine_record` 保存对 `clip_asset` 的物理外键，删除行为固定为
`ON DELETE RESTRICT`。模块仍只能通过公开应用服务或查询接口访问彼此，禁止跨模块 Repository
注入和级联更新/删除。

## 理由

两类记录都是绑定特定视频摘要的合规证据，父对象标识稳定，V1.2 的用户删除是软删除。
受限外键可阻止绕过引用检查的物理删除，并且当前模块化单体共享同一 PostgreSQL 迁移序列，
不会引入跨服务部署耦合。

若未来拆分数据库或服务，必须先用一致性巡检和可验证迁移替代这些外键，再更新本 ADR。
