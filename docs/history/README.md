# 历史资料

本目录保存已经退出当前规范入口的设计、计划、验证和 UAT 资料。它们用于迁移、兼容性、审计或回溯，不定义当前产品范围。

当前产品唯一需求入口是 [V1.35 Consolidated Baseline](../requirements/baselines/V1.35/配药视频数据处理平台需求文档_V1.35.md)。历史需求和架构导航分别见 [历史需求索引](../requirements/history-index.md) 与 [历史架构索引](../architecture/history-index.md)。

- `architecture/`：日期化审查与标注实施计划。
- `design/`：V1.27 连续工作流设计。
- `plans/`：V1.29 简化实施计划。
- `validation/`：V1.19 G0 与 V1.25 冻结验证记录。

归档仅改变文档入口，不删除内容，也不改变 runtime、数据库迁移或公开契约。
