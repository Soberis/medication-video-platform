# V1.28 单一导出边界设计

> 状态：CURRENT / DESIGN FROZEN
> 生效日期：2026-09-04
> 当前需求基线：[V1.28 配药视频数据管理平台需求基线](../../requirements/baselines/V1.28/配药视频数据管理平台需求文档_V1.28.md)

V1.28 不改变 V1.27 的 CaptureGroup 主链，只删除没有直接服务手部机器学习数据的第二个事件 manifest 出口。完整业务与领域约束继续参见 [V1.27 单一 CaptureGroup 产品路径](./v1.27-single-capture-group-workflow.md)；该文档现作为上一版本参考。

## 当前边界

```text
CaptureGroup → CameraStream / ClipAsset → MediaPipe Candidate
                                      ↘ hand-landmarks.v1 CSV
```

- `datasetexport` 只提供 `hand-landmarks.v1` 的同步只读 preview/download。
- 项目列表和 CaptureGroup 详情使用同一导出契约，前者不带 `capture_group_id`，后者带一个 `capture_group_id`。
- 导出只读取当前 CameraStream、ClipAsset 和 Candidate evidence；不读取人工质量、AnnotationRevision、Review 或 Cleaning。
- Cleaning 仍是事件事实和人工闸门的一部分，但不再生成另一份训练资格 manifest。
- V75 只删除旧 eligibility views；CaptureGroup、Review、Cleaning 和 MediaPipe 事实不删除、不改写。

## 极简原则

不保留别名路由、第二套 JSON envelope、split 校验、独立导出任务、DatasetVersion 或新的抽象层。历史 Flyway 迁移和历史文档保留，以保证数据库升级链和审计可追溯；它们不属于当前运行时。
