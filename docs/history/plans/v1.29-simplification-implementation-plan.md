# V1.29 Runtime Simplification 实施计划

状态：待批准；依据 `docs/history/audits/v1.29-runtime-simplification-audit.md`。
目标：以最小纵向切片把默认路径收敛为“数据组 → 媒体检查 → MediaPipe evidence → `hand-landmarks.v1`”，保留可选的 human-label 路径和所有可靠性/历史事实。

## 共同边界

- 先获得业务与技术批准：谁可为项目启用 human ground truth、显式创建任务的命令语义、权限、idempotency、审计、以及既有 task 的继续读取/处理规则。当前没有可据以臆造的 project-policy 字段。
- 三个实施项按 A → B → C 执行；每项可独立回滚到前一个应用版本，且不得回滚/删除数据库 migration、审计、媒体、Candidate、Revision、Review 或 Cleaning 事实。
- 默认不新增表、project-wide workflow engine、持久化 stage/`next_action`/`blockers`、新 Worker/queue、DatasetVersion、CaptureSync、训练平台或批量数据平台。
- V1.29 在 A/B/C 完成且审批、契约、合成验收和 runbook 一致后，才可单独评估 DRAFT → CURRENT；本计划本身不改变版本状态。
