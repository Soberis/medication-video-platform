# V1.29 视频工作区体验补充

状态：2026-09-05 用户确认的前端体验调整；不变更服务端业务契约，不将 V1.29 DRAFT 冻结。

本补充优先于历史界面命名与工作台排列要求，视觉继续遵循 `docs/DESIGN_SYSTEM.md`。

## 用户目标

上传视频 → 查看与可选标注 → 导出数据。MediaPipe 检测独立进行，人工标注不是检测数据导出的前置步骤。

## 界面边界

- 主导航和列表称为“视频”。每条记录仍对应一次 CaptureGroup 采集，多相机保留在同一详情中；解释聚合范围时称“采集记录”，不新增独立视频任务或更改 API 身份。
- 播放器先于操作表单；单相机省略冗余相机选择与锁定状态，多相机显示明确切换和参考时间提醒。
- 标注准备明确列出当前服务端要求的质量检查；只有用户主动展开后呈现长表单，不能自动提交质量结论或绕过任务权限。
- 列表和详情统一提供“导出数据”入口，区分人工标注和 MediaPipe 手部关键点及导出范围。沿用两份现有文件和独立权限、预览、provenance 校验，不新增打包服务。
- 检测状态保持可见；技术参数、ID、历史和审计按需展开。列表没有检测汇总契约时不得编造检测进度。
- 标注的正式提交、复核、返工与规则检查保持现有语义；界面不把保存草稿、提交复核和训练完成混为一谈。

## 验收

在合成数据上检查列表、上传、单/多相机详情、标注、复核和两类导出；覆盖桌面及窄屏、键盘操作、错误恢复。格式、Lint、类型、单元测试、构建和关键浏览器回归通过后方可推送 dev。main 等待用户测试后另行授权。
