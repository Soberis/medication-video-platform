# 配药视频数据处理平台需求基线 V1.32

日期：2026-09-07  
状态：DRAFT / 待用户验收

继承 [V1.31](../V1.31/配药视频数据处理平台需求文档_V1.31.md)，以下为用户批准的工作区收敛变更。

- 视频页统一承载全部视频与待标注、待复核、待返工、已完成、我的待办视图。任务视图使用完整的服务端授权任务查询，不以已加载视频页冒充项目范围筛选。普通成员仍仅看分配给自己的任务；保留任务 runtime 与旧入口重定向。
- 等待状态紧凑呈现，不占用播放器右侧整列。按用户最新变更，保留一次管理员确认标注动作，允许确认自己提交的标注，不要求另一人复核；仍要求全局 ADMIN 与 ACTIVE 项目 ADMIN。提交不自动确认、不自动导出；保留不可变确认记录、准入检查与清洗事务。
- 视频列表通过「导出数据」弹层勾选一条或多条已加载记录导出；移除行内复选框与项目全部导出的 UI 入口。弹层列出视频名称、任务状态、是否可选及原因，并提供明确标为「勾选已加载」的辅助操作，不含未加载的视频。服务端仍校验完整 provenance 与准入，不将前端已审核状态等同最终可导出。旧 API 缺省范围保留兼容，不新增自动放行。
- 标签库为全局账号级资源；新增全局读取与管理员发布端点，不需要项目 Membership。保留项目读取端点供任务消费者使用，旧项目写入入口仍要求原项目管理员权限。全局发布审计不伪造项目归属；不可变 schema 与历史任务绑定不变。
- 上传属于工作区，标签库属于设置；视频列表标题展示项目名称。任务展开内容横跨整行，等待复核与提交人身份说明清晰，技术信息默认折叠、长标识可复制，审计区块不重复标题。

验收：验证授权任务范围、筛选与深链接、导出弹层单/多选及不可选原因、全局标签库无项目访问与成员禁止发布、管理员确认自己标注成功与普通成员确认被拒绝；更新 OpenAPI、相关契约和前端测试。仅使用合成数据；不改变生产账号、数据或真实服务。
