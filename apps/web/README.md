# Web

React 管理端。当前激活的纵向功能包括上传排障、护士配药 CaptureSession、单路视频资产查询、人工质量、标注复核，以及数据集草稿、划分、构建配置、准备检查、显式构建、关系快照、冻结前技术校验、独立冻结审批、冻结版本导出申请和按需导出审批准备检查。

## Commands

```powershell
pnpm run web:dev
pnpm run web:lint
pnpm run web:type-check
pnpm run web:test
pnpm run web:build
```

以上命令从仓库根目录运行；如在 `apps/web` 目录内工作，可分别使用 `pnpm dev`、`pnpm lint`、`pnpm type-check`、`pnpm test` 和 `pnpm build`。

开发服务器默认监听 `http://127.0.0.1:5173`（可由 `WEB_PORT` 覆盖），并把 `/api` 代理到 `http://localhost:8080`。Web 使用平台内部账号登录；密码不进入浏览器存储，服务端仅保存 BCrypt 哈希，浏览器通过 HttpOnly 会话 Cookie 与 CSRF Header 调用 API。项目可见性和 ADMIN/MEMBER 仍由后端 Membership 在每次请求中校验，前端从不自行授予权限。医院边端使用独立上传凭据，不使用 Web 登录页。

根路径重定向到 `/projects`，只列出当前用户具有 ACTIVE Membership 的项目。项目 ADMIN 可以修改项目显示名称或归档项目；归档会停止后续项目访问并从日常列表移除，但不物理删除项目、视频、对象或审计。进入项目后，`/projects/:projectId/sessions` 以一次护士配药操作为主对象展示多相机完整性、组装和质量状态，`/projects/:projectId/assets` 用于单路视频及项目内一层文件夹/未分类筛选；`/projects/:projectId/event-logs` 供项目成员按批次、设备和平台索引时间查询已验证的事件日志对象索引，不读取日志内容、不暴露存储地址或下载链接，也不推断设备动作。详情路由保持同一项目上下文。`/uploads` 继续只读展示批次和文件进度，`/uploads/new` 用于平台本地上传。

`/uploads/new` 已启用平台本地上传：用户选择已加入的项目、可选的一层文件夹和一个或多个本机视频；每个视频使用独立 `PLATFORM_LOCAL` 批次，浏览器先在 Web Worker 中分块计算 SHA-256，再复用 Upload/Multipart/Complete/CaptureSession 协议直传对象存储。页面只显示运行期批次 ID，不记录或输出预签名 URL；多视频按顺序执行，避免误组装为同一次多相机拍摄。

`/projects/:projectId/folders` 已提供项目内一层文件夹管理；管理员可创建、重命名和删除文件夹，删除只会将其中视频变为未分类。管理员也可在资产详情变更单个视频的分类；这些操作不改变项目权限或对象存储位置。

当前已支持项目成员在媒体检测完成后显式点击播放；播放地址短期有效、`no-store` 且不落库。资产详情可按需读取与当前视频明确关联的追加式操作记录；接口不返回审计详情 JSON、trace、授权引用、对象存储字段或媒体 URL，也不把操作记录误写成每一次内部技术状态变化。合格视频可以由管理员创建并分配标注任务，受分配成员可在任务页提交主 Step 时间段和可选说明；另一名项目管理员可记录一次通过/不通过复核。复核不通过会退回任务，标注人提交新的不可变 revision，旧记录仍保留。标注任务接口同时返回与当前身份可见范围一致的互斥进度计数，页面只用一行显示待提交、待修改、待复核和已完成，不从其他分页数据推算。Session 满足当前技术检测、人工质量、复核和 post-clean 准入条件时，项目管理员可显式创建 `DRAFT` 数据集草稿；服务端会重新校验并固定成员与证据快照。项目成员可在 `/projects/:projectId/datasets` 查询版本列表及固定的 session/stream 摘要，页面不请求媒体 URL。拥有至少两个成员时，项目管理员可为草稿固定一次 CaptureSession 级 pilot/holdout 划分，页面显示策略版本、seed 和实际结果；标签和清洗摘要一致后，还可确认一次不可变构建配置，把候选快照、划分和当前 `p0-dataset-export-v2` 绑定到草稿，历史 v1 记录仍可显示。所有写请求重试均复用同一幂等键，固定后如需调整必须新建草稿。按需构建准备检查只读返回当前准入、固定证据差异及剩余阻断项；零阻断时，管理员可在同一区域确认“开始构建”，服务端再次校验后才进入 `BUILDING`。管理员随后可在原区域生成关系快照封印：服务端复用既有成员、原始视频、标注、清洗和划分事实，记录确定性摘要后进入 `VALIDATING`。管理员可在同一区域执行一次冻结前技术校验；唯一 `PASS` 结果会建立待审批请求，另一位项目管理员看到“批准并冻结”动作。批准命令重新检查全部技术证据，并原子记录审批决定、审计和 `FROZEN` 状态；申请人不能自批，证据变化或 `FAIL` 必须新建 DatasetVersion。`FROZEN` 后，项目管理员可在独立“数据集导出”区域选择授权到期时间并提交固定 `MODEL_TRAINING` 用途的申请；项目成员可显式执行只读审批准备检查，页面只显示真实角色、有效期和冻结证据阻断，不写审批、不入队，也不伪造文件进度。当前尚不包含导出审批动作、后台生成、下载、抽样复核或 P1 的 Object/COCO，也不包含外部 IdP、跨浏览器/医院网络的容量 UAT、上传中断后继续同一批次的页面恢复、派生视频或独立隐私流程。资产详情提供管理员软删除与项目内分类入口；视频软删除会立即阻断播放和后续业务使用，但不会在 P0 中直接物理删除对象或审计。

认证会话使用 React Context；批次、资产、标注和数据集等服务端对象继续使用页面局部状态，不复制为客户端业务真值。
